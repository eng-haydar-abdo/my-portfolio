# Haydar Thaeer Abdo - Professional Portfolio

Welcome to the official repository of my personal portfolio website! This project showcases my dual expertise as a **Junior Flutter Mobile Application Developer** and a **Cyber Security Penetration Tester (Red Team)**, along with my background in Computer Engineering and AI tools.

---

## Features

- **Dual-Specialization Focus:** Toggle or seamlessly view projects and skills tailored specifically for Mobile Development (Flutter) and Offensive Security (Penetration Testing).
- **Multilingual Support:** Fully responsive with Arabic (AR) and English (EN) language switcher, including full RTL support for Arabic.
- **Dark & Light Mode:** Sleek theme switcher featuring a modern cybersecurity dark vibe and a clean professional light mode.
- **Dedicated CV Downloads:** Direct download buttons for specialized resumes:
  -  Download Flutter Developer CV (PDF)
  -  Download Penetration Tester CV (PDF)
- **Interactive Projects Showcase:** Highlighting e-commerce apps (Food CR, Labetak, Hstore), web platforms (Your Bank, Hstore Website), and cybersecurity labs.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, React / Tailwind CSS
- **Mobile Development:** Flutter, Dart, GetX, Provider, Clean Architecture, Firebase
- **Cybersecurity & Tools:** Kali Linux, Metasploit, Burp Suite, Nmap, Wireshark, OWASP Top 10
- **AI & Emerging Tools:** ChatGPT, Gemini, DeepSeek, GitHub Copilot
